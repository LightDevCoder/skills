# Skill Catalog

## Foundation state

No first-party Skill has been admitted to this repository yet. A package may
appear here only after it has passed the required admission and final
`review-loop agent-skill` acceptance gates.

When packages exist, this catalog must be synchronized from the authoritative
package metadata and identify at least the Skill name, purpose, invocation
type, installation path, status, and applicable attribution. It is a
human-readable inventory, not a static workflow router and not a substitute for
the Skills actually installed in an agent environment.

See [maintenance](docs/MAINTENANCE.md) for the synchronization procedure and
[admission](docs/SKILL_ADMISSION.md) for the entry gate.
