# Skill categories

[简体中文](README.zh-CN.md)

36 skills grouped by purpose. Each category explains its scope and separates user-invoked from model-invoked skills.

| Category | Count | Purpose |
| --- | ---: | --- |
| [Project delivery](project/README.md) | 8 | Frame a project, settle its requirements, implement bounded work, then release and learn from the result. |
| [Engineering](engineering/README.md) | 5 | Configure execution, diagnose bugs, explore implementations, write tests, and resolve merge conflicts. |
| [Review and acceptance](review/README.md) | 4 | Separate read-only findings, repair convergence, and final project acceptance. |
| [Clarification and research](thinking/README.md) | 5 | Resolve user-owned decisions and gather the evidence needed to make them. |
| [Learning and knowledge](knowledge/README.md) | 5 | Learn a subject, explain ideas, turn sources into reusable methods, and initialize knowledge libraries. |
| [Writing and editing](writing/README.md) | 3 | Create governed manuscripts, improve natural prose, and write clear instructions for agents. |
| [Everyday tools](productivity/README.md) | 6 | Find the right skill, hand off work, summarize a session, guide manual steps, or prepare a travel page. |

Source packages live at `skills/<category>/<name>/`. Skill names, invocation modes, and installed `<skills-root>/<name>/` paths are unchanged.
