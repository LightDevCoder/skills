# Generic Profile

Select this Profile when the artifact target and approved acceptance source are
already defined and no narrower Profile has been accepted for the work.

## Additions to the Core

This Profile adds no artifact-specific review axes, evidence requirements,
specialist reviewers, severity overrides, acceptance conditions, or failure
cases. Apply the Core's baseline, evidence, finding, repair, independence,
state, limit, and verdict rules without extension.

## Selection record

Record `Profile: generic` in the Acceptance Charter and state why no narrower
Profile applies. A later request to use a narrower Profile is a baseline change
unless it was already approved in the Charter.
