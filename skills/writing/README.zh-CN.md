# 写作编辑

[English](README.md)

组织稿件生产、改写生硬文案，以及编写清晰的 Agent 指令。

分类只用于浏览，不新增流程或批准要求。技能自身的 `SKILL.md` 是行为权威。

## Agent 或用户调用

- **[humanizer](humanizer/SKILL.md)** — 将带有 AI 痕迹的中英文文本改写为自然行文，且不改变原意。
- **[manuscript-ops](manuscript-ops/SKILL.md)** — 从小笔记到多语言多格式交付的文稿工程治理。
- **[writing-for-agents](writing-for-agents/SKILL.md)** — 为 agent 编写或改进面向模型的文档（Skills、AGENTS.md、CLAUDE.md）。
