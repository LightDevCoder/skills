# Writing and editing

[简体中文](README.zh-CN.md)

Create governed manuscripts, improve natural prose, and write clear instructions for agents.

Categories organize browsing; they add no workflow or approval gates. Each package’s `SKILL.md` is the behavior authority.

## Model- or user-invoked

- **[humanizer](humanizer/SKILL.md)** — Rewrite AI-sounding English or Chinese text so it reads naturally without changing what it says.
- **[manuscript-ops](manuscript-ops/SKILL.md)** — Route and govern manuscript engineering from notes to multilingual, multi-format deliverables.
- **[writing-for-agents](writing-for-agents/SKILL.md)** — Author or edit agent-facing documents (Skills, AGENTS.md, CLAUDE.md) for model consumption.
