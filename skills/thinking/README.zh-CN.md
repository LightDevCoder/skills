# 澄清研究

[English](README.md)

澄清想法与决策，研究外部事实，或为掌握信息的人准备问题。

分类只用于浏览，不新增流程或批准要求。技能自身的 `SKILL.md` 是行为权威。

## 用户显式调用

- **[clarify](clarify/SKILL.md)** — 一次调用启动面向模糊想法/需求/流程的连续澄清，不产生正式 SPEC。以一轮多问题形式询问当前 frontier，并接受批量回复。
- **[decision-map](decision-map/SKILL.md)** — 将大型、模糊、跨会话的工作规划为可持久化的决策地图 tickets。
- **[to-questionnaire](to-questionnaire/SKILL.md)** — 将未决问题转为面向持信息人的问卷。

## Agent 或用户调用

- **[socratic](socratic/SKILL.md)** — 核心澄清引擎——内部 decision frontier 以一轮多问题呈现，含选项、建议、批量回复与共同理解确认。
- **[research](research/SKILL.md)** — 针对外部问题做高可信来源调研并沉淀结论。
