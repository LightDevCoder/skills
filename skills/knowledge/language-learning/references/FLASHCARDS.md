# Instant Flashcards

Turn a list of words or phrases into flashcards.

## Card anatomy

For each item, produce one card:

- **Target** — the word/phrase in the target language.
- **Definition** — in the learner's language, plain. Prefer the most common
  everyday meaning first. Mention secondary meanings only when they are
  likely to matter to the learner.
- **Usage** — one example sentence in the target language with a gloss in the
  learner's language. Prefer a sentence the learner could actually use.
- **Memory tip** — one hook: a mnemonic, a cognate, a sound association, or a
  false-friend warning. Beginner-friendly — no jargon.
- **Pronunciation** (only when relevant) — a simple phonetic note or audio
  hint: stress, tone, tricky clusters, "sounds like…". Skip when the spelling
  already says how it sounds. When the target language is English, include
  stress or IPA only when pronunciation is non-obvious, commonly
  mispronounced, or specifically requested — not on every card.

## Steps

1. List every word/phrase the learner gave — none dropped.
2. Build each card from the anatomy above.
3. Present the cards as a set the learner can review or read aloud.

## Example

For a card like `run`, give the everyday meaning first and stop there, rather
than listing a dozen senses:

> **run** — 跑
>
> Example: I usually run in the park after work.
>
> Memory tip: Think of someone running with their legs moving quickly.

## Completion

Every item the learner gave has a card with a target, definition, usage, and
memory tip. Each card is retrieval-friendly: cover the target, recall it from
the definition and example.
