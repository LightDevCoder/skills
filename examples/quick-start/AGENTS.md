# Quick Start example rules

This is a minimal documentation fixture for the public Skills collection.

- Read `brief.md` before selecting a Skill.
- Use only explicit `$ask-light`, `$project-init`, or `$project-review` entry
  points appropriate to the current state.
- Do not automatically invoke, install, edit, commit, or publish a later Skill.
- Stop at each handoff and preserve `NEED-INPUT`, `BLOCKED`, or final verdicts.
- Treat outputs in the README as illustrative unless a command is recorded in
  a real evidence file.
