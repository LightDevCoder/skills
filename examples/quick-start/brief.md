# Minimal Quick Start brief

## Goal

Prepare a small, inspectable project brief for a source-backed documentation
experiment.

## Inputs

- `brief.md` is the only supplied artifact.
- No implementation files exist yet.
- The user has not approved a specification, ticket graph, or final acceptance
  source.

## Boundary

The first decision is whether `ask-light` or `project-init` is the appropriate
explicit entry point. This brief does not authorize an automatic chain or a
release.
