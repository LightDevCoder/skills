# Validated Combination Examples

This directory holds future, evidence-backed examples of Skills used together.
No combination example exists in the foundation state because no package has
been admitted yet.

An example must identify the participating released or candidate Skills, the
state that made the combination useful, its invocation boundaries, and the
evidence that validated the interaction. It may show a successful composition
or a boundary that correctly stops or recommends another user-invoked Skill.

Examples are documentation and validation assets. They never determine whether
a Skill is admissible, and they must not become a predefined canonical workflow
or an automatic orchestration rule.
